# Advanced CLI Note Taker 📝

A modular, error-resistant Command Line Interface (CLI) note-taking application written in Python with persistent JSON storage.

> **Note on Language:** Prompt messages, function names, and user interface outputs are intentionally written in Turkish. Feel free to translate or adapt them to your own language!

## Features ✨

* **Full CRUD Operations:** Create, Read, Update, and Delete notes seamlessly.
* **Persistent Storage:** Saves all notes to a local `notlar.json` file.
* **Error Resistant:** Handled file I/O errors, invalid inputs, and sudden process terminations (`KeyboardInterrupt`).
* **Interactive CLI Menu:** Custom ASCII menu for navigating through options.

## Requirements ⚙️

* Python 3.x
